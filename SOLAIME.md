# Fork Solaime de cal.diy

Ce fork sert au deploiement de l'agenda de prise de rendez-vous de Solaime
Energies, sur Vercel, projet `solaime-cal`, domaine
`cal.solaime-energies.com`.

Rien n'est modifie par rapport a `calcom/cal.diy` : le fork existe parce que
Vercel a besoin d'un depot auquel il a acces pour construire. Pour suivre les
versions amont : `git fetch upstream && git merge upstream/main`.
